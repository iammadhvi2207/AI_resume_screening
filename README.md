# 📌 About the Project

The **AI Resume Screening System** is an intelligent web application that automates the resume evaluation process using **Machine Learning** and **Natural Language Processing (NLP)** techniques.

The application helps recruiters and hiring teams quickly analyze resumes, compare candidate skills, and identify the most suitable applicants based on relevant qualifications and experience. Instead of manually reviewing hundreds of resumes, users can upload candidate resumes and receive AI-powered insights instantly.

Developed using **Python**, **Scikit-Learn**, **NLP**, and **Streamlit**, the project demonstrates an end-to-end AI workflow, from text extraction and preprocessing to candidate evaluation and deployment as a user-friendly web application.

# 📝 How It Works

### Step 1

Upload a candidate's resume.

### Step 2

The application extracts text from the uploaded resume.

### Step 3

The extracted text is preprocessed by:

- Converting text to lowercase
- Removing punctuation
- Removing stopwords
- Tokenization
- Lemmatization

### Step 4

The processed resume is converted into numerical features using **TF-IDF Vectorization**.

### Step 5

The Machine Learning model analyzes the resume and extracts meaningful information.

### Step 6

The application provides an AI-powered evaluation to assist recruiters in the screening process.

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/iammadhvi2207/AI_resume_screening.git

cd AI_resume_screening
```

---

## Create Virtual Environment

```bash
python -m venv venv
```

### Windows

```bash
venv\Scripts\activate
```

### Mac/Linux

```bash
source venv/bin/activate
```

---

## Install Dependencies

```bash
pip install -r requirements.txt
```

---

## Run the Application

```bash
streamlit run app.py
```
